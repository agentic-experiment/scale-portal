# Scale Portal

## Step-by-step reasoning

1. **Concept.** A 2D canvas puzzle game where the player moves through a world of platforms and portals. Each portal teleports the player to its paired portal and applies a scale factor, changing the player's size and speed. The player must collect all shards before reaching the golden exit.

2. **Tech choice.** Plain HTML/CSS/JS with Canvas 2D and Web Audio. No build step, no dependencies — GitHub Pages serves static files directly.

3. **Structure.** `index.html` hosts the canvas, HUD, and overlay. `style.css` styles the HUD/overlay. `game.js` contains all game logic: input, physics, collision, portals, particles, camera, levels, audio.

4. **Levels.** Three hand-authored levels with increasing platform count, portals, and shards. Level data is plain objects (platforms, portals with pair indices and target scale, shards, start, exit).

5. **Mechanics.** Circle-vs-AABB collision, velocity integration with friction, scale affects radius and max speed, portal cooldown prevents bounce loops, shard collection unlocks exit.

6. **Visuals.** Radial gradients, glow rings, particle bursts, motion trail, parallax starfield, bobbing shards, pulsing portals/exit.

7. **Audio.** Web Audio oscillators for portal sweeps, shard pickups, level clear. Created lazily on first interaction.

8. **State flow.** Menu → play → win/complete overlay → next level or replay.
